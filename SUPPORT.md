# Support

## hushscreen issues

For bugs, feature requests, and questions about hushscreen itself, open an issue or start a discussion in the hushscreen repository:

- Issues: https://github.com/kalyanreddy1009/hushscreen/issues
- Discussions: https://github.com/kalyanreddy1009/hushscreen/discussions

## Server problems

hushscreen is a web client. Problems with the Jellyfin server, its libraries, or its settings belong to the Jellyfin project. Use the Jellyfin project's own channels:

- Documentation: https://jellyfin.org/docs/
- Forum: https://forum.jellyfin.org
- Matrix troubleshooting channel: https://matrix.to/#/#jellyfin-troubleshooting:matrix.org

Do not report server problems in the hushscreen issue tracker.
